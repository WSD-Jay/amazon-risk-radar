# 亚马逊跨境经营风险雷达

每天 09:15（Asia/Singapore）由 GitHub Actions 运行原生 Node.js 脚本，从公开官方页面和 RSS/JSON 来源生成一篇静态日报并发布到 GitHub Pages。

不使用 OpenAI API Token，不依赖 Codex，不在本机运行后台进程。微信公众号与卖家社区只作为线索；自动版不能替代人工政策核验。

固定覆盖亚马逊卖家论坛、Amazon Ads、SP-API、CPSC、USTR、CBP、USITC、欧盟 TAXUD、HMRC、IRS、深圳海关、海关总署、马士基、MSC 和 SCFI，并用三组 Google News RSS 做免费主题发现。线索来源统一标记“待官方确认”，新增来源首次成功只建立基线。
